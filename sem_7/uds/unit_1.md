## Principles of UCD

- **UCD** is an apprach in which software is designed by focusing on
- needs, behaviour, expectations of users

1. Focus on Users and their needs
2. Iterative Design
3. Complete User experience
4. User involvement
5. Research and data driven
6. Accesibilty and Inclusivity

### Primary objective of UCD

- make software easy, efficent and satisfying to use
- Process: understnad → specify → Design → Evaluate

## UCD Process

1. understand the context of use
2. specify user requirements
3. Design solutions
4. Evaluate against requirements

## Principle of Iterative design

- process in which product is designed, tested, evaluated and refined
- continuous improvement
- process:
  Design → Prototype → User testing → Feedback ↓
  Identify Problems → improve design → test again

### How iterative design improves usability

1. identifes usability problem
2. incorporates real user feedback
3. improves ease of use
4. reduces errros
5. improves usser satisfaction
6. Allows continuous improvement

## How Accesibilty supports UCD

- Accesibilty means designing products so that they can be used

3. improves usabilty
4. encourages user involvement
5. supports inclusive design
6. improves user satisfaction

## Ergonomics

- designing app to minimize user's congnitive / physical strain
- during long period of use

### how is improves usabilty (strenghts)

1. reduces congnitive load
2. easy target acquisition
3. Accesibilty

### Weaknesses of poor ergonomics

- high congnitive load
- small touch targets
- poor placement of controls
