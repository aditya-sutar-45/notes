# Unit 3

## Project Design Lifecycle

- structured multi stage process that guides a project from vague idea
- to fully functional and tested product
- not a simple / linear process
- iterative cycle

### Stages

1. Discovery
2. Define
3. Design
4. Implement
5. Usabilty testing

## Impact of iteration and refinement Lifecycle

1. identifies Usabilty problems
2. improves design
3. helps redefine the problem
4. reduces dependence on assumptions
5. Improves Usabilty
