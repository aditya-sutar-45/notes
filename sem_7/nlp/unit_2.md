# Unit 2

## Rotokas dictionary entry

- **toolbox** is a lexical data management tool
- toolbox lexicon is made up of entries
- each entry contains one or more label-information field pairs

- for rotokas word "kaa" meaning "to gag" represented as:

```md
\lx kaa → lx (lexeme)
\ps V → ps (part of speeach, V = verb)
\ge gag → ge (gloss / english meaning)
```

### Major fields

1. lx
2. ps
3. ge
4. other fields (grammatical info, translations)
